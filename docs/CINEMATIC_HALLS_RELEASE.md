Для мобильной панорамы поставляется версия 1920×1080 (0.31–0.55 MB у планет); координаты точек сохраняют связь с предметами. Подготовленные портретные изображения 1080×1920 используются в декоре окон, а не вместо панорамы с точками. Интерьер обсерватории — 1672×941 для ПК/панорамы, отдельная портретная композиция — 941×1672 для декора; это не 4K. Старые версии изображений оставлены для выборочного отката.
