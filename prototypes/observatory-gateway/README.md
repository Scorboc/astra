# Кольцо света — отдельный прототип

Адрес при запущенном локальном сервере ASTRA: `/prototypes/observatory-gateway/`.

Это независимая сцена PlayCanvas по утверждённому кадру `design/observatory-options-2026-10-09/10-ice-metal-ring-in-galaxy.png`. Она не встроена в четыре основных раздела сайта, не читает профиль и не сохраняет персональные данные.

В сцене есть две ледяно-металлические колонны, розово-коралловое световое кольцо, бирюзовый вертикальный луч, остеклённая обсерватория с подходом, облачный слой, три текстурированные планеты и дальний пояс астероидов. Текстуры планет повторно используют существующие файлы проекта; облака, лёд и световые градиенты создаются локально в браузере.

Управление: «Подойти к входу», «Общий вид», «Другой ракурс», небольшое вращение перетаскиванием, остановка движения. `Back` и `Forward` возвращают ракурс входа/общего вида. При системной настройке уменьшенного движения анимация изначально остановлена.

Это проверка композиции и производительности, **не точная копия** иллюстрации: процедурная архитектура имеет более простые формы, облака и свет без кинематографического постпроцесса, а астероиды не повторяют рисунок эталона. Для соответствия 1:1 понадобятся отдельная оптимизированная авторская 3D-модель обсерватории, материалы льда и металла с развёртками, художественные VFX кольца/луча и проверенная настройка света и постобработки. До утверждения этого прототипа основной сайт не менять.

Проверка сборки: `pnpm exec vite build --config prototypes/observatory-gateway/vite.config.js`.
