# Ледяная обсерватория — отдельная локальная модель

Адрес: http://127.0.0.1:5173/prototypes/observatory-blender/

Архитектура создана локально в Blender 4.5.14 LTS, экспортирована в GLB и показана в Three.js. Основной сайт, его сцена, личные данные и прежние прототипы не изменялись. Это визуальный образец, а не рабочий кабинет достижений.

## Актуальная ревизия 2 — 2026-10-09

Последующее уточнение эффектов: красная дымка вокруг кольца, зелёный объём вместо плоского луча, восходящий пар шпилей, подсвеченный снизу туман поверх прежних нижних облаков. Реализация — `energy-volume.js` и `volume-pass.js`: ограниченные 3D-поля плотности с пониженным разрешением прохода; не физическая симуляция жидкости. Общая пауза/«Без эффектов» действуют на новые слои. Для отката эффектов восстановить main.js и model.test.mjs из `../../backups/observatory-before-volume-20261009/`; новые модули станут неиспользуемыми. Геометрия остаётся ревизией 2. ### Визуальные ограничения

**Требование сходства не менее 95% не подтверждено и не считается выполненным.** Видимые различия: упрощённая геометрия и внутренние конструкции купола, чрезмерно зеркальный мост, повторяющиеся плоские облака, иное распределение туманности, отдельные контуры пластин и световые акценты. Фронтальная проекция не восстанавливает скрытые стороны из одного изображения. Число пройденных тестов не измеряет художественное сходство.

Для следующего уровня точности нужна ручная доводка узлов и UV/PBR-материалов в имеющемся Blender, раздельные карты цвета/шероховатости/нормалей без нарисованных бликов, сопоставление камеры с эталоном. Дополнительные боковые ракурсы или исходная 3D-модель позволят восстановить невидимые поверхности, а не придумывать их. Замена Three.js на другой движок сама по себе этого не решит.

## Файлы

- `assets/observatory.blend` — редактируемая модель.
- `assets/observatory.glb` — автономная переносимая геометрия с базовыми материалами: 1 434 432 байта, 58 684 треугольника, 9 групп материалов. Не содержит Tripo-модель, чужие закрытые ассеты или внешние URI.
- `build_model.py` — воспроизводимый сборщик архитектуры. Повторный запуск заменяет только эти производные ассеты. Blender сохраняет предыдущую версию как `.blend1`.
- `main.js` — окружение, материалы браузера, отражение моста, эффекты, планеты и управление.
- `model.test.mjs` — четыре проверки структуры, размера, материалов и изоляции.

GLB содержит только здание и мост с базовыми PBR-материалами. Трещины льда, кольцо, луч, облака, окружение и отражение моста находятся в браузерном коде и не входят в GLB. При переносе в PlayCanvas им понадобится соответствующая настройка материалов и эффектов.

## Управление

Тачпад вверх/вниз — движение камеры; горизонтальная прокрутка и перетаскивание — ракурс. Стрелки дублируют управление. Ctrl/Meta+wheel не перехватываются. Кнопки дают подлёт, общий вид, другой ракурс, паузу, просмотр без эффектов, скачивание модели и сравнение с эталоном. Подлёт использует настоящий hash и историю Back/Forward. На паузе движение отключено, повторная отрисовка происходит по взаимодействию. Системный reduced-motion учитывается.

## Воспроизвести

```powershell
& ./tools/blender-portable/blender-4.5.14-windows-x64/blender.exe --background --python prototypes/observatory-blender/build_model.py
node --test prototypes/observatory-blender/model.test.mjs
node node_modules/vite/bin/vite.js build --config prototypes/observatory-blender/vite.config.js
```
