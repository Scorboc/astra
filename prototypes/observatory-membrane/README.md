# ASTRA — обсерватория №2

Отдельный интерактивный прототип по `design/observatory-options-2026-10-09/02-membrane-observatory.jpg`. Основной сайт `/spatial/`, первый прототип обсерватории и вариант №3 не изменены.

При работающем локальном Vite: http://127.0.0.1:5173/prototypes/observatory-membrane/

Для сравнения с отдельной реализацией на PlayCanvas: http://127.0.0.1:5173/prototypes/observatory-compare/

Здесь есть трёхмерная площадка, четыре полупрозрачные створки с процедурной туманностью, золотая кромка, GLB-телескоп и облачная опора. Можно войти внутрь, вернуться, поменять ракурс и остановить движение. История `#outside` / `#inside` работает через адресную строку. Витрины — вымышленные пояснения, не реальные данные, достижения или подключённые функции ASTRA. Профиль и хранилище не читаются.

Сборка: `node node_modules/vite/bin/vite.js build --config prototypes/observatory-membrane/vite.config.js` из корня проекта.

Это не попиксельная копия концепт-JPEG: форма стеклянных створок, сложность световых отражений, детализация металлического телескопа и объём облака пока упрощены. JPEG служит эталоном для сравнения, но не подменяет 3D-сцену.
