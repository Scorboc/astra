# ASTRA / отдельная 3D-обсерватория

Открыть при работающем локальном Vite: http://127.0.0.1:5173/prototypes/observatory/

Не подключена к основным маршрутам и профилям. Не читает и не записывает хранилища. Все описания вымышленные. Основные src, настройки сайта и данные не менялись; используется только существующий генератор рамки membraneFrame и установленная Three.js.

Внешний вид: круглая платформа, колонны, открытый купол, телескоп и белая многослойная дымка. Нажатие на здание или «Войти внутрь» переводит камеру внутрь. Витрины доступны кнопками, экспонаты — также нажатием. Есть другой ракурс, перетаскивание внешней камеры, пауза движения, reduced-motion, Escape для описаний и история outside/inside.

Это геометрический прототип, не точная копия генерации: облако состоит из полупрозрачных слоёв, отражения используют окружение, фактура камня и предметы упрощены. Нет накопления достижений и интеграции с программой ASTRA. Следующий этап после визуального согласования — материалы, облака и интерьер; не интеграция без согласия.

### Облегчённая сцена (2026-10-09)

По умолчанию 110 облачных слоёв рисуются одним `InstancedMesh`, а телескоп загружается из локального `telescope-optimized.glb` (38 972 байта). Модель создана локально командой `node prototypes/observatory/make-telescope.mjs`; это **не** результат Tripo. Исходные варианты доступны для сравнения и отмены по адресу `?cloud=original&telescope=original`. Ошибка загрузки GLB возвращает исходный телескоп.

При 1280×720 снаружи измерено 324 вызова отрисовки и 60 926 треугольников в исходном режиме против 216 и 60 074 в новом. Кадры внешне близки, интерьер осмотрен. Показатель FPS фоновых вкладок нестабилен и **не подтверждает** ускорение на устройстве пользователя. Для этого нужен одинаковый активный браузерный сеанс и замер времени кадра на целевом компьютере/телефоне. Основная галактика пока не получает эти облака или GLB; её внешний вид не менялся.

Изолированная сборка: `node node_modules/vite/bin/vite.js build --config prototypes/observatory/vite.config.js` из корня. Результат находится только в prototypes/observatory/build. Для отдельной раздачи сборки требуется также существующий /ui/nebula-membrane-approved.png; автоматическая публикация не настроена.
