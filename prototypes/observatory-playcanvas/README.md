# ASTRA / обсерватория №2 на PlayCanvas

Локальный адрес: http://127.0.0.1:5173/prototypes/observatory-playcanvas/

Первый вариант на Three.js: http://127.0.0.1:5173/prototypes/observatory-membrane/

Страница выбора: http://127.0.0.1:5173/prototypes/observatory-compare/

PlayCanvas Engine 2.23.1 установлен локально как зависимость проекта. Сцена запускается без облачного Editor и без CDN, использует тот же локальный WebP-фон и тот же GLB-телескоп, что Three.js-вариант. Створки, золотые края, площадка и облака собраны на API PlayCanvas. Вход, возврат, другой ракурс, пауза, reduced motion и демонстрационные витрины доступны кнопками. Профиль, реальные наблюдения и хранилище не читаются.

Сборка: `node node_modules/vite/bin/vite.js build --config prototypes/observatory-playcanvas/vite.config.js` из корня ASTRA.

Это близкие, но не идентичные сцены. Отличаются материалы, форма облака, мелкая геометрия и освещение, поэтому сравнение FPS не является корректным тестом производительности самих движков. Оба варианта не копируют утверждённый JPEG попиксельно.
